# Agent instruction package

Start with the repository-root [router](../AGENTS.md), then the
[instruction landing page](instructions/README.md). Shared policy is in
`instructions/package/`; optional repository policy is in `instructions/custom/`.
The [architecture](instructions/package/docs/ARCHITECTURE.md) explains ownership and
additive synchronization. [REVIEW](REVIEW.md) is mutable repository-owned review state,
not an implementation task list. Its normative policy is in
[CODE_REVIEW](instructions/package/CODE_REVIEW.md) and its optional custom companion.
