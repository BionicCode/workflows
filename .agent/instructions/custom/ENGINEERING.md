# Workflows engineering companion

This is `BionicCode/workflows`, the implementation-authority repository for reusable
GitHub Actions workflows and associated tooling, distinct from downstream caller or
template repositories.

Implementation locations include `.github/workflows/`, `.github/scripts/` and
publisher sources under `deployment/packages/`. No primary .NET solution governs
this repository. Follow the existing tool-specific testing and documentation layouts
before applying generic directory or project defaults.
