## 5. Cross-document contradictions

1. **Instruction authority versus actual repository layout**

   `AGENTS.md:401–405` correctly identifies `.github/workflows/`, `.github/scripts/`, tool-local tests, and root/tool documentation. Its remaining placeholders and the copied Copilot, .NET, source, test, guardrail, and documentation files instead imply a Visual Studio solution with `src/`, `test/`, and `docs/`. Affected:

   - `AGENTS.md`
   - `.github/copilot-instructions.md`

2. **Path-specific Copilot instruction format**

   GitHub requires an `.instructions.md` file to have starting frontmatter containing `applyTo`.
